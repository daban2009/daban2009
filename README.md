# 🐍 贪吃蛇游戏

一个使用原生HTML、CSS和JavaScript开发的现代化贪吃蛇游戏。

## ✨ 特性

- 🎮 流畅的游戏体验
- 🎨 现代化的UI设计
- 📱 响应式布局，支持移动设备
- 🏆 本地最高分记录
- ⏸️ 游戏暂停功能
- 🎯 多种控制方式（方向键/WASD）
- 💫 渐变色彩和动画效果

## 🎯 游戏说明

- 使用方向键（↑↓←→）或WASD键控制蛇的移动
- 吃到红色的苹果会增加分数和蛇的长度
- 避免撞到墙壁或蛇身，否则游戏结束
- 按空格键可以暂停/继续游戏
- 游戏会自动保存你的最高分记录

## 🚀 快速开始

1. 克隆或下载项目文件
2. 在浏览器中打开 `index.html` 文件
3. 点击"开始游戏"按钮开始游戏
4. 享受游戏乐趣！

## 🎮 控制方式

| 按键 | 功能 |
|------|------|
| ↑ 或 W | 向上移动 |
| ↓ 或 S | 向下移动 |
| ← 或 A | 向左移动 |
| → 或 D | 向右移动 |
| 空格键 | 暂停/继续 |

## 🛠️ 技术栈

- **HTML5**: 页面结构和Canvas画布
- **CSS3**: 现代化样式设计，包括渐变、阴影、动画
- **JavaScript (ES6+)**: 游戏逻辑和交互控制
- **Canvas API**: 游戏画面渲染
- **LocalStorage**: 本地数据存储

## 🎨 设计特色

- 使用CSS渐变和毛玻璃效果
- 响应式设计，适配不同屏幕尺寸
- 平滑的按钮悬停动画
- 美观的游戏结束提示界面
- 现代化的配色方案
